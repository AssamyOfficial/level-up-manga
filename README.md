# LEVEL UP: Цена желания

Оригинальная цветная корейская манхва о деньгах, социальном статусе, романтике и игровой системе DESIRE.

## Концепция

Кан Мин-джун, 21-летний студент из Сеула, живёт почти без денег и привык быть невидимым для окружающих. Однажды он получает систему, которая превращает искренние траты ради других людей в задания, опыт и денежные награды. Деньги открывают ему доступ к элитному обществу, но не избавляют от зависти, одиночества и необходимости разбираться в людях.

Главная тема: в обществе, где человека оценивают по его кошельку, Мин-джун должен выяснить, кто рядом с ним ради богатства, кто ради статуса, а кто видит в нём самого человека.

Этот репозиторий — основной источник истины для сценария. Если решение меняется, сначала обновляем соответствующий документ здесь. Иллюстрации, созданные позже, должны соответствовать последней версии документов.

## Производственный процесс

1. Утвердить библию мира, персонажей и механику системы.
2. Подготовить визуальные референсы персонажей.
3. Разбить главы на сцены и панели.
4. Создавать иллюстрации без встроенного текста.
5. Собрать вертикальные страницы, добавить реплики и системные окна.
6. Проверить последовательность, внешность персонажей и непротиворечивость системы.
